# AITU Rubezh

Открытые инструменты для студентов Astana IT University. Бесплатная замена платным
планировщикам вроде upahead.com — с той разницей, что эти знают правила именно нашего
университета.

Всё работает **локально, на твоём компьютере**. Сервера у проекта нет, аккаунт заводить
негде, твои данные никуда не уезжают.

| | |
|---|---|
| [**rubezh/**](rubezh) | Дашборд: дедлайны, расписание, оценки и рубежи допуска к экзаменам |
| [**tg-digest/**](tg-digest) | Выжимка из университетских Telegram-групп: дедлайны и объявления без флуда |

## Зачем

Университет уже знает всё, что тебе нужно. Проблема в том, что это знание размазано по
трём системам, которые не разговаривают друг с другом, и ни одна из них не отвечает на
единственный важный вопрос: **успеваю ли я и что будет, если не успею.**

`rubezh` собирает Moodle, портал и почту в одну страницу и считает по формуле AITU:

```
Итог = 0,3 × РК1 + 0,3 × РК2 + 0,4 × итоговый экзамен
```

И, что важнее, следит за барьерами, по которым курс заваливают, даже когда с баллами всё
в порядке:

- посещаемость ниже **70%** — не допустят до экзамена;
- меньше **25%** за любую из аттестаций — автоматический незачёт;
- среднее РК1 и РК2 ниже **50** — не допустят до экзамена.

Последний порог есть в письме университета, но его нет в силлабусе. Студент, у которого
РК1 = 42, обычно не знает, что теперь ему нужно **58** за РК2 просто чтобы дойти до
экзамена. Инструмент говорит это прямо.

## С чего начать

### Windows — установщик

Скачай `AITU-Rubezh-Setup-<версия>.exe` из [Releases](https://github.com/dias-2008/AITU_Rubezh/releases),
запусти, дальше «Далее → Далее → Готово». Python, Chromium и всё остальное внутри
(~190 МБ), ничего доустанавливать не надо, права администратора не нужны.

На последнем экране установщик предлагает запустить мастер: он откроет окно входа в
Moodle, потом в портал, спросит про Telegram — и соберёт дашборд. Минут пять.

> **Windows напишет «Windows защитила ваш компьютер».** Установщик не подписан
> (сертификат стоит денег), поэтому SmartScreen предупреждает о любом новом файле.
> Нажми «Подробнее» → «Выполнить в любом случае». Что внутри — можно проверить:
> установщик собирается из этого репозитория на GitHub Actions, см.
> [.github/workflows/release.yml](.github/workflows/release.yml).

Учишься в **CS-2606** — отметь галочку «Я из группы CS-2606» на экране дополнительных
задач: установщик положит расписание и силлабусы группы из [groups/](groups/).
Остальным расписание придёт с портала, силлабусы — `python rubezh.py syllabus`.

Ярлык на рабочем столе открывает дашборд. Удаление — как у любой программы,
через «Приложения»; при удалении спросит, стирать ли сессии и ключи.

### macOS

Установщика нет, но всё работает из исходников — одной командой:

```
git clone https://github.com/dias-2008/AITU_Rubezh.git
cd AITU_Rubezh && sh install.sh
```

Нужен Python 3.11+ (`brew install python`). Скрипт ставит зависимости в `.venv`,
скачивает Chromium и запускает тот же мастер. Ярлык на рабочем столе — файл
`.command`, проверка раз в час — агент launchd. **Проверено пока только на
Windows:** macOS-ветка написана по документации, если что-то не так — открой issue.

### Из исходников на Windows

```
git clone https://github.com/dias-2008/AITU_Rubezh.git
cd AITU_Rubezh
install.bat
```

Или руками: `pip install -r rubezh/requirements.txt`, `python -m playwright install chromium`,
`cd rubezh`, `python rubezh.py setup`.

Дальше — [rubezh/README.md](rubezh/README.md): там про уведомления в Telegram, фоновую
проверку раз в час и про то, почему всё ходит через браузер, а не через API.
Второй инструмент, [tg-digest](tg-digest), настраивается отдельно: `python digest.py setup`
(в установщике — галочка «tg-digest» и ярлык «Настройка tg-digest» в меню Пуск).

## Безопасность

В репозитории **нет** ключей, кук и сессий — всё перечислено в [.gitignore](.gitignore).
Если ты форкнул проект, проверь это сам перед первым `git push`: файл
`tg-digest/university.session` — это полный доступ к твоему аккаунту Telegram, а
`rubezh/secrets.json` — к оценкам и календарю.

## Статус

Собрано в конце августа 2026, до начала учебного года. Ядро проверено на живых системах
AITU, дашборд пока работает на демо-данных: до 07.09 в Moodle и на портале пусто.
Расчёт оценок и календарь — настоящие.

Сделано для AITU, но переносится на любой Moodle: правила оценивания лежат в одном файле
[rubezh/grade.py](rubezh/grade.py).
